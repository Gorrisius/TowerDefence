# Як працює формула влучання

Додатковий розбір до [уроку про турель](Instructions_and_Logic.md). Читай після звичайного руху кулі.

## Яке запитання розв’язуємо

Куля за крок проходить відрізок. Ворог має круглу область влучання. Треба знайти відстань від початку відрізка до входу в коло.

| Назва | Значення |
|---|---|
| start | Позиція кулі на початку кроку |
| _direction | Напрямок довжини 1 |
| length | Довжина руху за крок |
| offset | start − позиція ворога |
| HitRadius | Радіус кола ворога |
| distance | Відстань уздовж польоту до входу в коло |

## Звідки b, c і discriminant

Точка на шляху — `start + _direction * t`. Вона на межі кола, коли квадрат відстані до центру дорівнює квадрату радіуса:

```text
|offset + _direction * t|² = HitRadius²
```

Розкриваємо дужки. Довжина напрямку дорівнює 1, тому:

```text
t² + 2*b*t + c = 0
b = offset.Dot(_direction)
c = offset.LengthSquared() - HitRadius * HitRadius
```

Це квадратне рівняння. Його корені — відстані до входу й виходу з кола:

```csharp
float discriminant = b * b - c;
if (discriminant < 0)
    continue;
float distance = c <= 0 ? 0 : -b - Mathf.Sqrt(discriminant);
```

Від’ємний discriminant означає відсутність перетину прямої з колом. Мінус перед коренем обирає ближній перетин. Якщо `c <= 0`, куля вже всередині або на межі кола: відстань до влучання — 0. Запис `умова ? A : B` обирає A при істинній умові, інакше B.

## Приклад із числами

Куля в `(0, 0)` летить праворуч. Ворог у `(10, 0)`, радіус 2. Довжина кроку кулі — 12.

```text
offset = (-10, 0)
direction = (1, 0)
b = -10
c = 100 - 4 = 96
discriminant = 100 - 96 = 4
distance = 10 - sqrt(4) = 8
```

Куля входить у коло в точці `(8, 0)`. Відстань 8 менша за крок 12: влучання відбувається цього кадру. При кроці 5 вона ще не долетіла б.

## Навіщо додаткові перевірки

```csharp
if (distance < 0 || distance > length || distance >= nearest)
    continue;
```

- distance < 0: перетин позаду кулі.
- distance > length: перетин за межами цього кроку.
- distance >= nearest: уже знайшли ближчого ворога.

`continue` переходить до наступного ворога. `return` завершив би весь метод — це інша дія.

Для придатного перетину запам’ятовуємо `nearest = distance` і `first = enemy`. Після циклу або рухаємося на весь step, якщо first порожній, або ставимо кулю в точку влучання:

```csharp
GlobalPosition = start + _direction * nearest;
```

**Перевір себе:** додай у приклад другого ворога в `(6, 0)` з радіусом 2. Вхід у його коло на відстані 4, тому він має отримати влучання першим незалежно від порядку ворогів у групі.
